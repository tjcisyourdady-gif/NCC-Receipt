# NCC 收款结算单自动化填报工具（V7）

NCC 收款结算单批量自动制单工具（Windows 桌面版），基于 Python + Tkinter + Playwright（内置 Chromium）+ openpyxl + Excel 无损粘贴宏，支持单条与并表制单、自有底稿一键对照转换、表头/明细独立顺序调整以及双版本（正常版 / 可修改时间版）运行。

本项目的源码、离线测试、空白模板与完整发行包均维护在独立仓库 [NCC-Receipt](https://github.com/tjcisyourdady-gif/NCC-Receipt)。

## 快速使用（完整包）

1. 从 [Releases](https://github.com/tjcisyourdady-gif/NCC-Receipt/releases) 下载最新 V7 完整 ZIP 包，**全部解压**到不含特殊符号的本地目录（切勿在压缩包内直接双击运行）。
2. 打开解压后的目录，按需运行：
   - `收款结算单填写工具V7-正常版.exe`：日常使用，采用固定默认等待时间。
   - `收款结算单填写工具V7-可修改时间版-卡顿使用.exe`：网络或 NCC 页面卡顿时使用，支持在界面调整各项等待秒数。
3. 使用自带的 `收款结算单底稿导入模板.xlsm`（33 列，含防精度丢失无损粘贴宏）整理数据，或通过主界面 **`设置数值转换`** 搭配 `对照表方案.xlsx` 将自有 Excel 一键转换为标准底稿。
4. 点击 **`开始运行`** 后在自动弹出的浏览器中登录 NCC，程序将自动进入“收款结算”节点逐笔制单并回写单据编号、填写状态与异常原因。

详细业务字段规则与使用说明见 [V7双版本及GUI功能说明.txt](V7双版本及GUI功能说明.txt)。

## 核心特性

- **33 列标准底稿与选填扩展**：支持部门编码/部门（选填）、收款银行账号（必填）、付款银行账号（选填）、备注（选填，兼容多行文本），同时向下兼容旧版 29/30/31 列底稿及旧版对照表方案。
- **表头 / 明细独立填写顺序设置**：主界面提供 **`填写顺序设置：设置顺序/停用`** 弹窗，配置保存至程序同目录 `收款结算单填写顺序设置.json`：
  - 严格限制**仅表头与表头、明细与明细各自内部互换顺序**，禁止表头与明细之间跨区互换。
  - `结算财务组织`、`单据日期` 固定最前；`付款银行账号` 固定在**所有数据（含全部明细）填妥后、点击保存/保存提交前最后一个填入**。
  - 支持对选填项（`备注`、`项目档案`、`部门`、`辅助核算`、`付款银行账号`）按需停用，保存时自动校验 NCC 联动先后依赖。
- **多维度防错与防重机制**：
  - 银行账号/公司编码/部门编码/客商编码全链路文本精度保护与科学计数法拦截。
  - 业务文本自动规范中文标点并保留 `-`、`/`、`\` 等半角分隔符。
  - 点击保存/提交前自动回写防重复标记，报错时安全关闭弹窗、取消当前单据并记录异常原因。

## 源码运行与离线测试

开发环境推荐使用 Python 3.12～3.14：

```powershell
python -m pip install -r requirements.txt
python 收款结算单工具.py
```

运行全部离线单元测试（无需启动浏览器或连接 NCC）：

```powershell
python run_offline_tests.py
```

## 打包构建

安装打包依赖并执行构建脚本可生成双版本 EXE（需准备内置 Chromium 浏览器目录）：

```powershell
python -m pip install -r requirements-build.txt
python build_scripts/build_release.py
```
